# Image Prompts: Sage the Owl

I am about to ask you to generate seven different poses for a book mascot.
Please use a consistent drawing style for all seven images.

Each prompt below is fully self-contained — the complete base character
description is repeated in every prompt so any one of them can be used on
its own to (re)generate that pose without drift from the others. Recommend
generating at 1024x1024 pixels, then resizing down for use, and running the
padding trimmer described at the bottom of this file.

## 1. Neutral / Default Pose

Please generate a new pose for Sage the Owl.
A flat vector cartoon illustration of Sage the Owl, a friendly pedagogical
mascot for a systems thinking textbook. Sage has slate-blue feathers (hex
#2E6DA4) with a cream chest, and wears small round orange-framed glasses
(hex #F5871F). Sage has bright, curious eyes and a warm, closed-mouth
smile. The character is small and compact with rounded owl body
proportions, roughly two heads tall, sized for icon-scale display.
Style: flat vector cartoon, clean lines, bold simple shapes, transparent
background with alpha channel, suitable for embedding in educational
content. No text in image.

Sage stands upright in a relaxed, neutral pose facing the viewer directly,
with a calm and friendly closed-mouth smile. Wings rest naturally at
Sage's sides with no specific gesture. The pose is balanced and
unassuming — suitable as a general-purpose or default illustration.
Filename: neutral.png

alpha-channel background. The background MUST be fully transparent with an
alpha channel. DO NOT use a white, black, or checkered background.

its prompt above, then trim excess transparent padding so Sage displays at
full size inside the 90px admonition boxes:
