# Causal Loop Diagram Viewer

There are two versions of the CLD viewer.  The main full version shows all of the menus
for loading new CLDs from the examples directory.  The main with the menus=false option
only displays a single CLE that is passed in as a URL file=myFile-cld.json parameter.

[Run the CLD Viewer with Full Menus with the Bank Balance Example](main.html?menu=true&file=bank-balance-cld.json)

[Run the CLD Viewer with no menus as used in iframe references](main.html?menu=false&file=bank-balance-cld.json)
