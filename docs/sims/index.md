# List of MicroSims for Systems Thinking in the Age of AI

Interactive Micro Simulations (MicroSims) that let you explore feedback loops, stocks and flows, emergence, and knowledge graphs hands-on. Click any card to open the MicroSim.

<div class="grid cards" markdown>

-   **[Bathtub Stock and Flow Simulator](./bathtub/index.md)**

    ![Bathtub Stock and Flow Simulator](./bathtub/bathtub.png)

    Set inflow and outflow rates independently and predict whether the stock rises, falls, or holds steady.

-   **[Breadth-First Search Step-by-Step](./bfs/index.md)**

    ![Breadth-First Search Step-by-Step](./bfs/bfs.png)

    Advance breadth-first search one ring at a time and predict which vertices it must visit next.

-   **[Capability Maturity Model for Systems Thinking](./cmm-for-systems-thinking/index.md)**

    ![Capability Maturity Model for Systems Thinking](./cmm-for-systems-thinking/cmm-for-systems-thinking.png)

    An interactive infographic microsim that shows the five-level of a capability-maturity model for enterprise systems thinking.

-   **[Causal Loop Diagram Viewer](./cld-viewer/index.md)**

    ![Causal Loop Diagram Viewer](./cld-viewer/cld-viewer.png)

    A reusable viewer that renders causal loop diagrams from JSON files, with optional menus for loading example CLDs such as the bank balance loop.

-   **[Cause-and-Effect Chain](./cause-effect-chain/index.md)**

    ![Cause-and-Effect Chain](./cause-effect-chain/cause-effect-chain.png)

    Trace a printer that jams every afternoon back through four intermediate causes to its root cause.

-   **[CLD Editor](./cld-editor/index.md)**

    ![CLD Editor](./cld-editor/cld-editor.png)

    An interactive editor for building causal loop diagrams: add and edit variables, polarized links, delays, and reinforcing or balancing loops, then save the diagram as JSON.
