# Society of Mind — Concept Knowledge Graph

An interactive concept knowledge graph (CKG) of Marvin Minsky's *The Society of Mind* (1986).

The book contains **30 chapters** and **270 self-contained essays** exploring how human intelligence
emerges from the collective activity of many simple, mindless agents.

## Key Concepts

**Agent** — The fundamental building block. A simple, mindless process that performs a single
narrow task. No agent is intelligent on its own.

**Society of Mind** — Agents organized into agencies, which nest into larger agencies.
Intelligence *emerges* from their collective interactions.

**K-line (Knowledge Line)** — A wire-like memory structure that re-activates the set of
agents that were active when you learned something, reinstating that mental state.

**Frame** — A data structure representing a stereotyped situation, with *slots* for expected
properties and *default* values when information is missing.

**Trans-Frame** — A frame specialized for representing actions and transitions,
with Origin, Trajectory, and Destination slots.

**Censor** — An agent that suppresses another agent, preventing unproductive actions
without knowing why they are wrong. Freudian-style suppression as a cognitive mechanism.

**Papert's Principle** — New mental abilities come not from learning new primitives but
from building new higher-level agencies to manage existing skills.
