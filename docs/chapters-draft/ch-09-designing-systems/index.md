# Chapter 9: Designing Human-Centered AI Systems

## Learning Objectives:
- Apply systems thinking to AI system design
- Consider multiple stakeholder perspectives
- Design for positive feedback loops and human flourishing

## Key Topics:
- Human-centered design principles
- Multi-stakeholder system design
- Positive feedback loops for human development
- Anticipating system behaviors and side effects

## Capstone Project:
Students design an AI system intervention using systems thinking principles, including:
- System mapping and CLD creation
- Stakeholder analysis
- Leverage point identification
- Implementation strategy with feedback mechanisms
