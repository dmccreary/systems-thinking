This file is read by the codex command line interface at startup.

## Rules for Finding Skills

1. Always first check in the ~/.codex/skills directory for skills
2. If you can't find the skill there then look in ../claude-skills/skills
3. If both these do not work, then look in /Users/danmccreary/Documents/ws/claude-skills/skills

Always verify with the user you have found the skill and the location you found the skill.

Prompt the user with a question when the skill indicates you should do this.
